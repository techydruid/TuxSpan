# TuxSpan 0.21.1

TuxSpan brings Linux workspaces to compatible Android phones and tablets without root. Connect the official Termux and Termux:X11 apps, choose a workspace, and follow the guided installation.

## Workspaces

- **Canvas:** a Debian desktop for everyday applications.
- **Studio:** an Ubuntu desktop with creative and development options.
- **Spark:** a lightweight Alpine Linux terminal.

Graphical workspaces support landscape and portrait layouts, touchpad and direct-touch controls, and external keyboards and mice. Starter applications, optional app packs, and Android Downloads sharing are available through the app.

## Improvements in this release

- Package configuration no longer waits for configuration-file answers during setup. Existing configuration is kept, and interrupted package setup can resume without deleting the workspace.
- Termux displays a clear completion or failure message and returns to its normal command prompt automatically. No Enter-key step is needed to finish setup.
- TuxSpan records setup completion automatically and shows the installer error if setup fails.
- Manual setup uses the same progress and completion tracking as in-app setup.

## Download and install

1. Install [Termux from F-Droid](https://f-droid.org/en/packages/com.termux/).
2. For Canvas or Studio, install `termux-x11-universal-debug.apk` from the [official Termux:X11 nightly release](https://github.com/termux/termux-x11/releases/tag/nightly). Use the regular universal APK, not the `sharedUid` variant with F-Droid Termux.
3. Download **TuxSpan-0.21.1.apk** below and install it.
4. Open TuxSpan, complete the connection checklist, and choose a workspace.

## Updating

This is a standard production-signed release, not a debug build or prerelease. Install it over your existing production version. The production signing certificate is unchanged.

If an earlier setup stopped with code 100 and an `updatedb.conf` configuration-file prompt, update TuxSpan and use **Run setup again**. Your existing workspace files are kept. Other package errors still require resolving the cause reported by the installer.

Do not uninstall Termux or clear its data to update TuxSpan: Linux workspaces are stored there. For conflicts with legacy development APKs, follow the [package-conflict guide](https://github.com/techydruid/TuxSpan/blob/v0.21.1/docs/TROUBLESHOOTING.md#tuxspan-apk-conflicts-with-an-existing-package).

## Requirements

Android 8 or newer, a supported processor architecture, and sufficient storage and memory for the chosen workspace. For a graphical desktop, allow approximately 8–10 GB of free storage and preferably at least 4 GB of RAM. Performance and application compatibility vary by device. TuxSpan does not replace Android or provide every Linux kernel or GPU feature.

Termux and Termux:X11 are separate applications. TuxSpan is not affiliated with those projects or the Linux distributions it supports.
