# TuxSpan 0.21.0

TuxSpan brings Linux workspaces to compatible Android phones and tablets without root. It guides you through connecting the official Termux and Termux:X11 apps, installing a workspace, and launching or managing your Linux sessions.

## Workspaces and features

- **Canvas:** a Debian desktop for everyday applications.
- **Studio:** an Ubuntu desktop with creative and development options.
- **Spark:** a lightweight Alpine Linux terminal.
- First-time connection checklist before choosing a workspace.
- Visible package installation in Termux alongside estimated progress in TuxSpan.
- Landscape and portrait display settings, touchpad/direct-touch input, and external mouse/keyboard support.
- Starter applications plus optional Creator and Developer packs.
- Optional Android Downloads sharing with guided Termux storage access.
- Separate workspace storage, with Launch, Reconnect, Restart, and Stop controls.

## Installation

1. Install [Termux from F-Droid](https://f-droid.org/en/packages/com.termux/).
2. For Canvas or Studio, install `termux-x11-universal-debug.apk` from the [official Termux:X11 nightly release](https://github.com/termux/termux-x11/releases/tag/nightly). Do not choose the `sharedUid` variant with F-Droid Termux.
3. Download **TuxSpan-0.21.0.apk** from this release and install it.
4. Open TuxSpan and complete **Connect TuxSpan** on Home, then choose a workspace.

See the [beginner installation guide](https://github.com/techydruid/TuxSpan/blob/v0.21.0/docs/INSTALLATION.md) for permissions, progress, first launch, and Android Downloads access.

## Updating and package conflicts

This is a production-signed standard release, not a debug build or prerelease. Install it over an existing production version; uninstalling is not required. The production signing certificate is unchanged.

Legacy debug APKs used the same app ID with a different certificate. If Android reports a package conflict, a legacy copy may remain in another Android user or profile even after the main-user copy was removed. Follow [package-conflict recovery](https://github.com/techydruid/TuxSpan/blob/v0.21.0/docs/TROUBLESHOOTING.md#tuxspan-apk-conflicts-with-an-existing-package). Remove only the conflicting legacy TuxSpan copy after checking its settings/data. **Do not uninstall Termux, clear its data, or delete an Android profile.** Linux workspaces are stored in Termux.

New development builds use the separate **TuxSpan Dev** identity to avoid this conflict in future.

## Requirements and limitations

Android 8 or newer, a supported processor architecture, and enough storage and RAM for the selected workspace are required. For a graphical desktop, allow approximately 8–10 GB of free storage and preferably at least 4 GB of RAM. Performance and application compatibility vary by device. TuxSpan does not replace Android or provide direct access to every Linux kernel/GPU feature.

Termux and Termux:X11 remain separate applications. TuxSpan is not affiliated with those projects or with the Linux distributions it supports.
